# 实验一设计与实施计划

依据原实验要求实现 Qt 6.9.2 C++ Widgets 程序，保留可在 Designer 中编辑的 calculator.ui。MainWindow 只负责信号、键盘和显示，CalculatorEngine 管理状态与四则运算。

步骤：

- [x] 2. 输入状态及数字、小数、退格、清除测试，先失败后实现。
- [x] 3. 四则运算与连续操作，测试后实现。
- [x] 4. 异常及边界回归：小数点重复、除零恢复、结果后输入、运算符替换、退格；保存原现象与修复证据。
- [x] 5. 鼠标与键盘共用入口，QtTest 验证一致性。
- [x] 6. 样式、真实截图、报告与 AI 记录。
